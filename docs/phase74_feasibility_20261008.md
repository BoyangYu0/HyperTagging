## Scientific interpretation and intended controls

Phase73 is terminal: both arms learned32/32 tiny raw memberships (28/32 accepted),
but both held-out raw and accepted counts are0/40. Main-train raw counts are2/256
frozen and30/256 adapted. The held-out gate failed. Sparse training fit leaves
representation, optimization and interface explanations open; it does not prove
irrecoverably absent encoder information or training-data scarcity.

A valid next campaign would compare exactly128-existing,128-assembly,
256-existing and256-assembly. Hyperbolic width32, encoder depth, curvature and
radius convention stay fixed. Both widths need comparable fresh pretraining
histories; objective arms share initialization and presentation order within
width. The authenticated70000-event corpus remains fixed, with any bounded
subset explicitly registered and reported at its actual size. Normalization
must remain train-only. The downstream head must have a common sufficient width,
consume predicted group representations, and permit encoder adaptation in all
four arms. Updates, checkpoint selection, data and search must match, while
parameters, actual presentations, time, memory and unequal compute are measured.

## Implementation assessment

The contextual encoder is configurable in width, but the Phase73 runtime is
hardcoded to two frozen/adapted arms and uses a historical128-wide checkpoint.
It supplies no new pretraining contrast and cannot be relabelled as this study.
The native pretraining trainer implements the existing topology, geometry,
channel, PID and corruption objectives. Its truth-guided/corrupted curriculum
is not an implementation of the requested model-generated partial-state
assembly supervision. Direct membership has an unordered loss, but no shared
membership-conditioned downstream decoder satisfying the new contract has been
implemented or admitted. A valid implementation needs genuine additional
within-B parent/sibling supervision and detector-only/generated-state paths,
with truth used only as supervision. No placeholder objective switches were added.

No four-arm gradient, head-use, convergence, resource or full-runtime checks
were run after cohort rejection. Training update/resource budgets and immutable
initializations were not admitted. Flat memberships cannot supply exact-B
hierarchy or deep-proposal survival; those endpoints need a justified diagnostic
implementation or explicit unavailability, never fabricated zero-success counts.
The tiny95% and held-out count/background/validity gates remain unchanged.
