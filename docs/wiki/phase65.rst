Existing auxiliary teacher supervision remains active for sampled predicted contexts. The inherited nominal expected-slot metadata used half the actual slot budget; it is preserved in native exports and explicitly corrected for the next preregistration. Native execution counts, not that stale metadata, define delivered exposure.

**Training size:** hold 70,000 for the next diagnostic. Phase40 changed data, update count and cohort together; no controlled learning curve establishes that data growth is necessary now. More training data could still help. A later equal-compute and equal-exposure size comparison, with fixed mixture and independent seed confirmation, is needed to measure that effect.

**Independent validation:** this is a different resource. Phase60 expanded validation without increasing training. The next 1,100-event reservation leaves 43,400 untouched validation events, so another expansion is unnecessary for this bounded campaign. Later source-domain confirmation remains important.

**Pretraining:** prioritize representation/objective usefulness and legal recursive supervision over merely longer duration, but do not claim that either beats data growth. Historical longer-pretraining comparisons did not show a downstream winner. Phase64 repaired saturation without joint recursive benefit; Phase65 shows preserving that geometry by freezing is insufficient. Neither is a comparison of improved pretraining against more data, nor proof that hyperbolic representation is better than a simpler representation. The immediate next allocation goes to a controlled assembly-training diagnostic, not an assumed pretraining winner.
