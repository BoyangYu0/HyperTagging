---------------------------------------


The September 28 `study ledger <https://github.com/BoyangYu0/HyperTagging/blob/master/docs/review_20260928/studies.md>`_ covers migration Phases1–13, early pretraining/transfer/resource studies, Stage A and reconstruction Phases34 onward. It found no standalone reconstruction closeouts numbered14–33; those numbers must not be invented. Historical software/runtime evidence, old full-tree labels and modern retained topology metrics are not interchangeable.

**Training data:** hold70,000 now. No controlled learning curve establishes immediate data limitation; larger data could still help. Once a useful recursive endpoint responds, run equal-compute and equal-exposure learning curves with fixed mixture and independent confirmation. **Validation:** independent capacity is a separate need. Phase60 expanded validation without growing training. After reserving the next1,100 events,44,500 remain; another expansion is unnecessary now, while future source-domain confirmation remains important.

**Pretraining/representation:** prioritize useful objectives, transfer and legal recursive assembly over more duration. This is a resource-allocation recommendation, not a causal finding that pretraining improvement beats data growth. Phase64 isolates one initialization repair; it does not compare no-pretraining versus pretraining, Euclidean versus hyperbolic, or representation work versus larger data. Saturation is no longer a sufficient explanation for the candidate’s poor primary topology. Target representability, proposal support, ranking calibration and first irreversible merge errors remain distinct hypotheses.

**Next bounded Phase65:** two4,376-step reconstruction runs from the same authenticated unsaturated Phase64 reconditioned final refinement encoder, with no extra pretraining. Compare existing late encoder adaptation (freeze2,188) with full encoder freeze (4,376). Keep the PID head frozen,70,000 events, objectives, architecture, thresholds, search and all original gates fixed. Seed20261001 controls fresh decoder/training/replay and cohort selection. Reserve1,000 selection and100 strict events (beam20) excluding all54,400 prior reservations. Resources remain one H100 NVL,8 CPUs,64 GiB and36h maximum per task.

The hypothesis is that preserving the usable representation may alter recursive transfer relative to late task adaptation; it does not assume adaptation destroyed radial gradients, which it did not on the measured samples. Historical frozen/adapted studies used older/saturated contracts and cannot answer this repaired-geometry contrast. Require original gates plus joint nontrivial topology/source and coherent-forest evidence, report depth >= 2 and paired uncertainty, and retain failures. Geometry, selection and checkpoint hashes are bound before scheduling. Same seed is not a bitwise common-prefix claim. No sweep, automatic successor, promotion, sealed test or increased budget follows.
