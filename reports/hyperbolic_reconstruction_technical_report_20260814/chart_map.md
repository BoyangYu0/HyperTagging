## Chart QA notes

- All 11 chart types are in the allowed contract: `bar`, `horizontalBar`, `stackedBar`, `horizontalStackedBar`, `horizontalStackedBar100`, and `line`.
- Every chart declares title, subtitle, intent, question, rationale, comparison context, dataset, source ID, canonical x/y encodings, supported palette metadata, axis titles, value format, unit, row bound, layout, settings, and surface behavior.
- Absolute bar charts carry a visible zero reference. Percent-composition charts use one-hot or share-valued rows whose within-bar sums are checked in tests.
- The six-point structural line uses an ordered reconstruction-level axis, not a temporal claim. The nine-point telemetry line meets the bounded trend-data requirement.
- Diagnostic memory and temperature stay in tooltips/table because combining them with utilization on one axis would mix units.
- The sealed test appears only as fixed role-size metadata in the subset chart and is labeled `sealedTestAccessed=false`.
- No chart treats diagnostic loss or utilization as evidence of convergence or scientific quality.
